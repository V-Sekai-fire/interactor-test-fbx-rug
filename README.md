# interactor-test-fbx-rug

A test fixture of one rug model with dense strand geometry, exported to binary FBX twice, for checking an FBX importer.

## What it is for

One export carries the strands as polygon meshes and has a gzip-compressed OBJ of the same model to compare an import against. The other carries them as NURBS curves; its OBJ holds no geometry. `rug.json` records the model's title, author and licence.
